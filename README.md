## How to run the project
To run the project download everything and run the mime_climb.py file.

## What it does
Tracks your hand movement in real time, and moves an alien character around the screen.

## How to use
Close your palm and drag to move the character.
To click on something on your screen, hold up your index finger in a pointer position and move it towards the camera.

## The vision
Designed to enhance online learning for children, especially those with learning challenges
